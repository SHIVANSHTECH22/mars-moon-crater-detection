# Mars and Moon Crater Detection

Deep learning based crater detection and classification on Mars and the Moon using Computer Vision.

## Overview

This project focuses on the automated detection and classification of impact craters in planetary surface imagery using deep learning and computer vision techniques.

## Models

- CNN
- YOLO
- ResNet-50

## Objectives

- Detect impact craters in planetary imagery
- Classify craters based on their size
- Compare different deep learning models
- Evaluate model performance using standard classification and detection metrics

## Technologies

- Python
- TensorFlow / Keras
- Ultralytics YOLO
- OpenCV
- NumPy
- Matplotlib
- Seaborn
- Plotly

This repository contains the implementation, experiments, and results associated with the research project.
